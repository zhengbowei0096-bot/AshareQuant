AshareQuant File Guide (文件逐项说明)

Numbered categories match the desktop workspace. Source files stay in their existing locations. (编号与桌面一致，源码保留原位置。)

Project home (项目首页)

These files remain visible beside the ten categories. (以下文件与十个分类并列展示。)

  • README.md — What the project does and how to run it. (项目用途与运行方法。)
  • requirements.txt — Dependency versions for installation/reproduction. (安装与复现用依赖版本。)
  • AGENTS.md — Required rules for future code, documentation and navigation changes. (后续代码、说明和导航同步规则。)

asharequant/models/__init__.pyPrediction module: models/__init__.py (统一暴露既有特征、拟合和推理函数；这里没有另一套预测算法。)

File (文件)Purpose (用途)

asharequant/research_policy.pyDecision and Risk module: research_policy.py (研究模拟的仓位分配：市场环境影响总仓位，个股结合预测与风险分配；不赋予正式资格。)

asharequant/risk/risk_control.pyDecision and Risk module: risk/risk_control.py (独立风险减仓模拟计划，只处理风险卖出方向，不因模型未通过而完全失去风控计划。)
asharequant/strategies/next_session_plan.pyDecision and Risk module: strategies/next_session_plan.py (下一交易日意向及其条件说明，把收盘后计划与当下能否成交分开。)
asharequant/strategy_experiment.pyDecision and Risk module: strategy_experiment.py (比较不同风险预算和执行阈值的研究方案，冻结对照输入并记录收益、成本及风险；不训练模型。)

asharequant/adaptive_intraday.pyExecution and Ledger module: adaptive_intraday.py (原动态模拟账户与迁移来源，冻结证据保留；当前主账户由 dynamic_service 管理。)
asharequant/execution_replay.pyExecution and Ledger module: execution_replay.py (按历史交易日重放候选订单，检查费用、涨跌停与交易状态；不能确认成交时不虚构成交。)
