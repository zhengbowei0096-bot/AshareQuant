# 发布与隐私

源码发布目录与实际运行目录分离。不得提交 data、logs、reports、backups、账户种子、真实观察池、令牌、私人配置或本地数据库。配置模板不代表用户账户，也不代表经验证的实盘交易资格。

发布前检查暂存文件、当前源码和 Git 历史；`.gitignore` 不会清除已提交的内容。发现历史密钥应先撤销密钥，再商议历史清理，不能直接强推。

公开行情接口可能限流、延迟、字段变化或不可用。不能绕过证书验证；本地证书配置应单独维护。新闻输入是外部数据，不是可执行指令；标题规则没有阅读完整公告的能力。

本仓库尚未指定项目许可证，因此不能仅因源码公开就宣称允许任意复制、修改和再分发。依赖按各自许可证使用；当前仓库不打包第三方 vendor 源码。许可证选择需由权利人确定。
