# 发布与隐私

源码发布目录与实际运行目录分离。不得提交 data、logs、reports、backups、账户种子、真实观察池、令牌、私人配置或本地数据库。配置模板不代表用户账户，也不代表经验证的实盘交易资格。

发布前检查暂存文件、当前源码和 Git 历史；`.gitignore` 不会清除已提交的内容。发现历史密钥应先撤销密钥，再商议历史清理，不能直接强推。

公开行情接口可能限流、延迟、字段变化或不可用。不能绕过证书验证；本地证书配置应单独维护。新闻输入是外部数据，不是可执行指令；标题规则没有阅读完整公告的能力。

本仓库尚未指定项目许可证，因此不能仅因源码公开就宣称允许任意复制、修改和再分发。依赖按各自许可证使用；当前仓库不打包第三方 vendor 源码。许可证选择需由权利人确定。

## Publication checklist (发布检查)

- 仅从独立源码目录发布，并先获取远程最新版本；保留远程已有修改，不强制覆盖。
- 同步源码、测试、非敏感模板、分类定义和说明。十个编号分类公开各自的 README 功能导航，仅链接审核清单中的源码、模板与文档；私人目录不上传内容，本机生成链接、启动器和清单仍排除。
- 核查暂存文件及待发布历史中的密钥格式、本机路径、账户标识和本地账户数值；使用本机密钥匹配时仅输出命中路径，不输出密钥。测试使用虚构数据。自动扫描不能替代人工审核。
- 校验配置初始化、全量自动测试、导入、文件说明和导航链接；记录本次范围，不把旧验收视为本次验收。
- 推送后核对远程分支提交与本地一致。`.gitignore` 不能消除历史泄露，也不保证任意命名的私人文件均被识别；新增文件必须先分类并审核。

公开项目名为 GuanlanQuant，运行包保留 `asharequant`。仓库不包含本机运行报告，也不提供带私人数据的演示页面。
